# hh.ru — компактная выдача

Пользовательский стиль для расширения [Stylus](https://github.com/openstyles/stylus), который ужимает список вакансий в поиске hh.ru. Карточка вакансии становится примерно в 2,5 раза ниже, поэтому на экран помещается больше вакансий.

## Что меняется

Каждая вакансия собирается в компактную карточку:

1. название вакансии, справа от него — «в избранное» и «скрыть»;
2. одной строкой — зарплата, опыт, компания, рейтинг, город и метро, плашки вроде «Можно удалённо»;
3. описание на всю ширину карточки;
4. маленькие кнопки «Откликнуться» и «Связаться» под описанием.

Кроме того, стиль:

- убирает логотипы компаний, пустые отступы и картинки у брендированных вакансий;
- скрывает блоки между вакансиями: «Компании для вас», курсы, баннеры и места под рекламу. Их можно вернуть в настройках.

## Установка

Сначала поставьте Stylus: для [Chrome, Edge и Яндекс Браузера](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) или для [Firefox](https://addons.mozilla.org/firefox/addon/styl-us/). Затем выберите один из способов.

### Из файла (Chrome, Edge, Яндекс Браузер)

Так появятся настройки стиля.

1. Скачайте [hh-compact.user.css](hh-compact.user.css).
2. Откройте страницу расширений (`chrome://extensions`), у Stylus нажмите «Сведения» и включите «Разрешить открывать файлы по ссылкам».
3. Перетащите скачанный файл в окно браузера. Stylus откроет страницу установки, там нажмите «Установить стиль».

### Вставкой кода (любой браузер)

1. Откройте [hh-compact.user.css](hh-compact.user.css) и скопируйте его целиком, от первой строки `/* ==UserStyle==` до последней `}`.
2. Нажмите на значок Stylus → «Управление» → «Написать новый стиль».
3. Удалите всё, что есть в редакторе, вставьте скопированный код и сохраните (Ctrl+S).

Стиль заработает со значениями по умолчанию. Если редактор открыл код как UserCSS (вверху видны название и версия стиля), будут доступны и настройки.

После установки обновите страницу поиска на hh.ru.

## Настройки

Значок шестерёнки у стиля в Stylus:

| Настройка | По умолчанию |
|---|---|
| Шрифт названия вакансии | 15px |
| Шрифт описания | 13px |
| Отступ между карточками | 6px |
| «Сейчас смотрят N человек» | скрыть |
| Рейтинг компании и отзывы | показать |
| Блоки между вакансиями (компании, курсы, реклама) | скрыть |

## Обновление

- Установлен из файла: скачайте новую версию и снова перетащите её в браузер. Stylus предложит обновить стиль.
- Установлен вставкой: откройте стиль в Stylus, выделите весь код (Ctrl+A), вставьте новый и сохраните.

## Если раскладка поехала

hh.ru время от времени меняет вёрстку, и часть правил может перестать срабатывать. Чтобы вернуть обычный вид, выключите стиль в меню Stylus.

Стиль написан на обычном CSS без препроцессора. Благодаря этому он работает и как UserCSS, и вставленный в Stylus без заголовка. При правках не добавляйте синтаксис Stylus или Less: при вставке без заголовка браузер молча отбросит такие правила.
